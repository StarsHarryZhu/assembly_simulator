# AGENTS.md

## 1. Role

English versions of the example programs one level up. The plugin shows these when the interface is in
English and the Chinese ones otherwise. Each file has exactly the same code as its Chinese twin, line
for line, so switching language keeps breakpoints and line numbers valid; only the title line and the
comments differ.

## 2. Constraints

- Same file names as the parent folder; same code after removing comments (tested).
- No Chinese characters (tested). The first line is `# <title>`.

## 3. Contents

- `welcome.asm` — array sum through a function call.
- `hello.asm` — hello world.
- `factorial.asm` — recursive factorial.
- `input.asm` — terminal input.
- `float.asm` — floating point.
- `heap.asm` — linked list on the heap.
- `exceptions.asm` — kernel exception handler.
